Peppol Sales Analytics V6.8.2 — Correzione avvio frontend macOS

Problema risolto:
- Il launcher precedente controllava solo l'esistenza della cartella frontend/node_modules.
- Se la cartella esisteva ma mancava il comando locale node_modules/.bin/vite, il frontend non partiva e il launcher restava in attesa.

Correzioni:
- Controlla direttamente che Vite sia eseguibile.
- Se Vite manca, esegue npm install per ripristinare le dipendenze.
- Se l'installazione fallisce o Vite resta assente, mostra un errore esplicito invece di lasciare il processo in attesa senza spiegazioni.
- Non modifica né elimina il database locale.

Requisiti: Node.js/npm e connessione internet al primo ripristino delle dipendenze.
Verifiche eseguite: controllo sintassi shell e integrità ZIP. Non è stato possibile eseguire una prova completa su macOS Apple Silicon.
