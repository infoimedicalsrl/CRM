Peppol Sales Analytics V6.9.2 — Correzione avvio macOS

Correzioni:
- Lo script crea/verifica automaticamente l'ambiente Python isolato in backend/.venv.
- Non tenta di installare librerie nel Python di sistema/Homebrew (errore externally-managed-environment).
- Controlla anche xlrd, necessario per importare file Excel .xls.
- Mostra un messaggio leggibile se non riesce a creare l'ambiente o installare le dipendenze.
- Conserva il database esistente nel pacchetto; per aggiornare un'installazione già usata, estrarre questa versione in una cartella nuova e copiare solo i dati necessari con cautela.

Requisiti: macOS, Python 3.9–3.13 disponibile, Node.js/npm e connessione Internet al primo avvio per installare le dipendenze mancanti.
