PEPPOL SALES ANALYTICS V6.0 – DDT FULL CONTENT IMPORT

- DDT parser rewritten around layout-preserving PDF extraction plus plain-text fallback.
- Product rows are segmented by product-code anchors instead of a fixed 5-line window.
- Each imported DDT line keeps product code, product description, quantity, unit, lot and expiry when present in the PDF.
- Product-looking tokens inside Lotto/Batch/Scadenza fields are no longer mistaken for product codes.
- Repeated/legitimate DDT rows are no longer globally deduplicated.
- OCR fallback now processes every PDF page instead of only the first 20 pages.
- DDT import response reports the number of loaded lines and field-extraction warnings.
- Original DDT PDF is preserved locally with collision-safe storage and can be opened from the DDT detail page.
- DDT detail now presents the complete extracted line table with explicit columns for codice prodotto, descrizione, quantità, unità, lotto and scadenza.
- All processing remains local; no PDF content is sent to external services.
